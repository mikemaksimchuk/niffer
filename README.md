# niffer

A single-page affirmation selector built around Jen's chaotic, cheese-fueled daily mindset.

This repository contains a static HTML page for selecting randomized affirmations from an 88-card deck.

## Files

- `index.html` — the published site for GitHub Pages
- `Jens_Daily_Affirmation_Selector.html` — the original standalone HTML version
- `CNAME` — custom domain configuration for `niffer.maksimch.uk`

## Local preview

Open `index.html` in a browser to view the site locally.

## GitHub Pages

The site is configured for deployment via GitHub Pages and is intended to be served at:

- https://niffer.maksimch.uk

## Notes

This is a static site with no build step required.
